# 🏠 Real Estate Portal (Bproperty Clone)

A modern real estate listing directory with advanced filters, interactive map view, and inquiry forms. Built with pure HTML, CSS, and vanilla JavaScript.

## ✨ Features

- 🔍 **Advanced Filters** — Filter by type, purpose, bedrooms, price, and location
- 🗺️ **Interactive Map** — Leaflet-powered map with property markers
- 📋 **Property Cards** — Responsive cards with images, prices, and details
- 📩 **Inquiry Forms** — Send inquiry directly from property detail modal
- 📱 **Responsive Design** — Works perfectly on mobile, tablet, and desktop
- ♿ **Accessible** — Keyboard navigation and ARIA labels
